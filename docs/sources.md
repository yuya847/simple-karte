# データと出典


- **患者・経過・検査値・培養・画像所見・バイタル・看護の記録**：すべて架空です（`src/lib/patients.ts`、`src/lib/vitals.ts`）。画像は模式図で、実際の画像ではありません。
- **病棟の配置と、受け持ち以外の患者**：架空です（`src/lib/ward.ts`）。受け持ち以外の患者のカルテは、ベッドの名前・年齢・診療科・注記（術後・明日退院・転倒注意・酸素投与中・飛沫予防策など）からコードで毎回同じに作る小さな記録です（`src/lib/ward-charts.ts`：入院日、主病名と病名、入院時の記事、バイタル数回、採血1回、食事、オーダ数件）。病名とコードは傷病名マスターのまま、薬・検査・処置はこのアプリのマスターのものだけです。DPC の分類はこの試作が持つ5つ（心不全・誤嚥性肺炎・腎臓又は尿路の感染症・膿皮症・敗血症）に当たる病名だけ出て、ほかは「コードなし」です。
- **勤務表と様式9**：看護師の名前・勤務・1日平均入院患者数は架空です（`src/lib/roster.ts`）。数え方は、告示「基本診療料の施設基準等」第五 一 (6)(7)・第五 二 (1) ロ ① 1・2（令和8年厚生労働省告示第70号、https://www.mhlw.go.jp/content/12400000/001675854.pdf ）と、通知「基本診療料の施設基準等及びその届出に関する手続きの取扱いについて」（令和8年3月5日 保医発0305第7号）の別添2 第2 4 (2)(3)(4)、別添6 別紙5、別添7 様式9 の記載上の注意によります（https://kouseikyoku.mhlw.go.jp/kantoshinetsu/kihon080305.pdf 、2026-11-04 に読んだもの）。夜勤時間帯 16:30〜翌8:30、1年目だけの夜勤にしない、夜勤明けの日は勤務を入れない、同じ夜勤に入れない組み合わせは、架空の病院の取り決めです。
- **処方（持参薬・定期・臨時）と救急外来の患者**：架空です（`src/lib/prescriptions.ts`、`src/lib/er.ts`）。内服薬の一般名・規格は公開されている事実の情報です。受付で入れた内容はブラウザの中だけにあり、サーバーには送りません。
- **保険**：デモの患者の保険者番号・記号・番号は架空です（形と検証番号だけ公的な決まりに合わせています。`src/lib/billing/insurance.ts`、`src/lib/billing/registration.ts`）。医事課が登録した保険はブラウザの中にあり、算定のときだけサーバーに送ります。
- **紹介割合・逆紹介割合**：厚生労働省「診療報酬の算定方法の一部改正に伴う実施上の留意事項について」（令和8年3月5日 保医発0305第6号）別添1 A000 初診料 (7)〜(9)・A002 外来診療料 (3)(5)(6)（https://www.mhlw.go.jp/content/12400000/001757385.pdf 、2026-11-04 に読んだ10月7日訂正後の版）。台帳・医療機関・外来の数は架空です（`src/lib/liaison.ts`）。
- **病床利用率・平均在院日数**：厚生労働省「令和7(2025)年 医療施設（動態）調査・病院報告の概況」の用語の説明（https://www.mhlw.go.jp/toukei/saikin/hw/iryosd/25/dl/11gaikyou07.pdf ）、入院基本料の平均在院日数は「基本診療料の施設基準等及びその届出に関する手続きの取扱いについて」（保医発0305第7号）別添2 第2の3・別添6 別紙4（https://www.mhlw.go.jp/content/12400000/001757361.pdf ）と告示第70号 別表第二（https://www.mhlw.go.jp/content/12400000/001675854.pdf ）。入退院の記録は今日のベッドからさかのぼって作った架空のものです（`src/lib/census.ts`）。
- **返戻・査定の CSV**：医療情報基盤・診療報酬審査支払機構「オンライン請求システム操作手順書 別添 印刷対象帳票・CSV・PDF作成対象ファイル＜医療機関（医科・DPC）用＞」（令和8年10月版、https://www.hpdx.or.jp/seikyushiharai/iryokikan/download/download_01.files/csv_ika.pdf ）の増減点連絡書・返戻内訳書の記録の形、別表6 事由コード、別表9 年号区分コード。模擬のファイルの患者・点数・査定は架空です（`src/lib/billing/returns.ts`）。
- **外来の受付**：診察券・予約の枠・診察室・診察の順番の決め方は架空の病院の取り決めです（`src/lib/opd-desk.ts`）。
- **放射線部**：照射録は診療放射線技師法 第28条（https://laws.e-gov.go.jp/law/326AC0100000226 ）と施行規則 第16条（https://laws.e-gov.go.jp/law/326M50000100033 ）、線量の記録は「医療法施行規則の一部を改正する省令の施行等について」（平成31年3月12日 医政局長通知）第2 4（https://www.ajha.or.jp/topics/admininfo/pdf/2019/190318_4.pdf ）、診断参考レベルは Japan DRLs 2025（https://j-rime.qst.go.jp/report/JapanDRLs2025_ja.pdf ）、造影剤の薬剤料は医科点数表 E300（https://www.mhlw.go.jp/content/12400000/001686842.pdf ）によります。撮影室・装置・AE タイトル・造影剤の採用品・読影する人は架空の病院の取り決めで、撮影条件・線量・受付番号・生年月日は架空です（`src/lib/ris.ts`）。
- **DICOM（撮影装置の模擬）**：DICOM PS3.4 K.6 Table K.6-1（https://dicom.nema.org/medical/dicom/current/output/chtml/part04/sect_K.6.html ）、F.7.2 Table F.7.2-1（https://dicom.nema.org/medical/dicom/current/output/chtml/part04/sect_F.7.2.html ）、PS3.6 のタグ・VR（https://dicom.nema.org/medical/dicom/current/output/chtml/part06/chapter_6.html ）、PS3.16 TID 10013（https://dicom.nema.org/medical/dicom/current/output/chtml/part16/sect_tid_10013.html ）。Orthanc の Worklists・DICOMweb プラグインは Orthanc Book（https://orthanc.uclouvain.be/book/ ）、dcm4che のツールは https://github.com/dcm4che/dcm4che （`src/lib/dicom-mwl.ts`、`src/lib/dicomweb.ts`、`docs/dicom-local.md`）。
- **リハビリテーション部**：単位・上限・標準的算定日数・早期リハビリテーション加算・休日リハビリテーション加算は医科点数表 第7部 通則4・H000〜H003（令和8年、https://www.mhlw.go.jp/content/12400000/001686842.pdf ）と留意事項通知（保医発0305第6号）別添1 第7部 通則3〜10（https://www.mhlw.go.jp/content/12400000/001757385.pdf ）、実施計画書は同 別紙様式21、Barthel Index の項目と点数は別紙様式7の2・21（https://www.mhlw.go.jp/content/12400000/001713885.pdf ）と厚生労働省の資料（https://www.mhlw.go.jp/content/12300000/001239045.docx ）、原典は Mahoney FI, Barthel DW. Md State Med J 1965;14:61-65。廃用症候群（Ⅲ）の扱いは施設基準通知（保医発0305第8号）第41の4（https://www.mhlw.go.jp/content/12400000/001757367.pdf ）。療法士・予約の枠・記録は架空です（`src/lib/rehab.ts`、`src/lib/barthel.ts`）。
- **薬と検査のマスター、院内セット、病棟の約束（定時採血 6:00 など）**：架空の病院の設定です（`src/lib/master.ts`）。薬の一般名・規格は公開されている事実の情報です。
- **薬の相互作用・配合**：PMDA「医療用医薬品 情報検索」の電子添文（各薬の先発品など、2026-11-04 に読んだ版。販売名・改訂年月・添付文書番号は `src/lib/interactions.ts` の `INTERACTION_SOURCES`）。文は電子添文の要約です。コードは何も勧めず、電子添文に書かれた措置は「電子添文は…としている」と出典つきで書きます。
- **規制区分・薬効分類・一般的名称**：同じ電子添文のヘッダ（2026-11-04 に読んだ版。品目ごとの製品と添付文書番号は `src/lib/drug-class.ts` の `DRUG_CLASSES`）。ハイリスク薬（薬剤管理指導料「1」の対象）は、留意事項通知（令和8年3月5日 保医発0305第6号）別添1 B008 (2) の分類に、電子添文の薬効分類名と有効成分で当てはめたもので、厚生労働省の対象薬剤一覧とはまだ照らしていません。看護必要度 A6 の麻薬の品目は、保医発0305第7号 別紙7 別表1（モルヒネ塩酸塩注射液１０ｍｇ「シオノギ」620009277・オキシコンチンＴＲ錠５ｍｇ 622576301）。
- **麻薬**：麻薬及び向精神薬取締法（https://laws.e-gov.go.jp/law/328AC0000000014 ）・同施行規則 第9条の3（https://laws.e-gov.go.jp/law/328M50000100014 ）・厚生労働省「病院・診療所における麻薬管理マニュアル」平成23年4月（https://www.mhlw.go.jp/bunya/iyakuhin/yakubuturanyou/dl/mayaku_kanri_01.pdf ）。麻薬施用者・麻薬管理者の免許番号、卸売業者と製品番号、最初の帳簿の数は架空です（`src/lib/narcotics.ts`、`src/lib/narcotic-book.ts`）。
- **推定クレアチニン・クリアランス**：Cockcroft-Gault の式（Cockcroft DW, Gault MH. Nephron 1976;16:31-41）。表示だけで、量の判定には使いません。
- **検査の基準範囲**：一般的な成人の基準範囲を、表示の H／L のためだけに使っています。
- **音声入力**：ブラウザ（Chrome）の音声認識を使います。Chrome では、音声は Google のサーバーで文字にされます。
- **ロゴ**：書体 Plus Jakarta Sans（SIL Open Font License 1.1、Tokotype）の字形を線にして、字間を整え、i の点を朱にしたものです（`public/simple-karte-logo.svg`、`docs/logo.svg`）。
