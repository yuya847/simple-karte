# 採用薬データの保守

内服600品目（通常の処方597、医薬品集のみの抗がん薬3）、実在の注射400品目、外用150品目。別に既存のデモ用インスリン5品目を保持する。外用にはオーダ経路を新設していない。

`src/lib/formulary-items.ts` の配列を人が編集する。品目名・単位・薬価・薬価基準コード等は公開の医薬品マスター `y_20261013.csv`（ローカルの `src/data/generated/y.json`）から抽出した。実在病院の採用リストは使用しない。追加品目の院内コードは9桁のレセ電コードを使う。配列の価格は原資料との照合用で、算定は従来どおりサーバーの公開マスターから現行薬価を読む。

配列の列はファイル冒頭に記載する。検索名は公開マスターの成分コードに対応する表記と、`formulary-expansion.ts` の一般名・商品名・略語の対応表を使う。ひらがな・カタカナ・大小文字・全半角を正規化する。コード検索はMap、検索の正規化は上限付きキャッシュを使い、クライアントからファイルシステムは読まない。

追加品目の薬効分類は薬価基準コード先頭3桁による分類であり、日本標準商品分類番号ではない。規制区分はマスター項番14の1=麻薬、2=毒薬、5=向精神薬だけを転記する。生物学的製剤フラグを生物由来製品とみなさない。劇薬・処方箋医薬品・生物由来は添文を読んだ品目だけに付ける。未確認を「区分なし」や「処方箋不要」と扱わない。ハイリスクは確認できる薬効群に限り、B008の個別対象一覧との照合は残る。

PMDA添文を今回確認した主要品目はメロペネム「明治」と経口バンコマイシン散「サワイ」。MEPMとバルプロ酸の併用禁忌を追加した。既存の併用注意は同一の薬価基準成分コードを持つ別規格にも適用する。配合変化は製品ごとの判定を維持する。相互作用表は網羅的ではない。

院内の運用として、注射の抗がん薬はレジメン限定、内服の抗がん薬3品目は内服レジメンの経路ができるまで医薬品集の表示だけにしている。追加薬のうち個別適応条件を未照合のものは病名漏れ点検の対象外理由を保持し、抗菌薬は既存の感染症ルールに加えている。新しい薬剤情報提供文書の個別説明は未整備で、薬剤師の確認を求める文面を表示する。

注射の規格・容量・電解質濃度はマスターの表記から取り込み、経路は剤形と品目の対応で設定している。全品目の投与経路・用法用量・添文の全項目の個別照合は完了していない。

## 確認

- `npm run check`：型検査、全vitest、eslint。
- `npx next build --webpack`：本番ビルド。Google Fontsを取得できるネットワークが必要。
- 医師で「院内医薬品集」を開き、MEPM・VCM 散・PIPC/TAZ・ひらがなで検索。「外用」の絞り込みとCSV出力を確認する。
- 医師で試験患者 `99000008`（ESBL）と `99000012`（CD腸炎）を開き、培養結果、薬剤変更、治療終了の記事・終了オーダを確認する。
- 注射の選択で実在のインスリンを選ぶ。経口VCM散は1回0.125g、薬価単位では0.5g瓶の0.25瓶に換算する。
