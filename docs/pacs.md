# 放射線画像のビューア（PACS ビューアの試作）

PACS（医用画像の保存と表示の仕組み）のビューアを、右のボタン列の「放射線画像」に入れた。設計の短いメモ。

## 決めたこと

- **画像は 2 種類。どちらも実在の患者の画像ではない。**
  - 公開データの本物の医用画像（2026-11-04 から）：Wikimedia Commons の CC0・CC BY-SA・パブリックドメインの教材用の画像（20 枚以内、`public/images/radiology/`。出典は `public/images/ATTRIBUTION.md` と `src/lib/image-credits.ts`）。架空の検査への割り当ては `src/lib/pacs/photos.ts`（レポートの所見と合うものだけ。新しいオーダーは部位の見本）。画面の上に「公開データ（Wikimedia Commons ほか）。架空の患者に割り当てた教材用の画像で、この患者のものではありません」を必ず描き、出典は hint で出す。画素の大きさ（mm）が分からないので、計測は画素の数（px）で出し、物差しは描かない。
  - コードで作る架空の合成画像：合う公開画像がない検査（下腿X線・胸部CT・MRI など）。画面の上に「架空の合成画像（実在の患者の画像ではありません）」を必ず描く（サムネイルにも「架空」）。
- 実在の患者の画像・DICOM ファイルは使わない。NC（非営利限定）や Radiopaedia の画像、矢印や丸の書き込みがある画像は使わない。
- **AI は使わない。** 所見を書かない・異常を判定しない。計測（距離・角度・ROI（関心領域）の平均と標準偏差、2 本の距離の比）はコードで計算し、計算の式を出すだけ。
- **同じ検査 ID からは毎回同じ画像。** `Math.random` は使わず、ID から作る種で擬似乱数を出す。体つきは患者 ID の種（同じ患者なら同じ体つき）、撮影のずれと雑音は検査 ID の種。
- 既存の架空の検査（`patient.imaging`）は読影レポートをそのまま使う。画像検査オーダーは時刻を過ぎたら画像が出て「読影待ち」、まだのものは「未実施」で画像なし。
- 架空のレポートに合わせた描き方（心胸郭比・胸水・うっ血・浸潤影・軟部の腫れ）は `FICTIONAL_HINTS`（`src/lib/pacs/studies.ts`）に書く。新しいオーダーは同じ部位の前回の描き方を引きつぐ。北村さんの胸部X線 2 回は CTR 62% → 58%、胸水が減る形で描くので、比較表示で並べると違いが見える。

| `src/lib/pacs/measure.ts` | 距離・角度・ROI と式 |
| `src/components/pacs/*` | canvas の表示枠、サムネイル、ビューア本体、キーボード操作の一覧 |

## 画面

- 左：検査の一覧（日付・種類・部位・読影済み/読影待ち/未実施・シリーズ数）。前回の検査に「前回」。
- 中：表示枠（四隅に患者名・ID・検査日・種類・部位・シリーズ・WW/WL・表示倍率・スライス番号と位置）、スライスのつまみ、明るさ・コントラストのつまみ（WL・WW）、シリーズのサムネイル。指で使う端末では 2 本の指のピンチで拡大縮小。
- 下（全画面では右）：読影レポート、計測と式、キーボード操作。
- 比較表示（C）：同じ部位・同じ種類の前回を左、今回を右に並べる。スライスの位置と拡大・移動・回転をそろえる（それぞれ切れる）。

## 作っていないこと

- 実際の DICOM の読み込み・保存、DICOMweb、読影レポートの入力。
- 計測の保存（画面を閉じると消える）。カルテへの貼りつけ。
- MPR（断面の作り直し）、3D 表示。
